# 試合・練習モードと走塁

開始メニューで「試合モード」または「練習モード」を選ぶ。Enterは従来の打撃練習を開始する。初期表示は英語で、Lまたは言語ボタンで日本語に切り替えられる。

## 試合モード

既定5球の攻撃チャレンジ。ストレート→カーブ→スライダーの順で投げる。得点、塁の占有状態、操作する走者を表示する。

1. Space／左クリックでスイングする。接触後は1塁への緑の矢印を表示する。
2. 打球の着地・フェンス到達後、フェアなら走塁へ進む。既定では25m未満は単打、25m以上は二塁打、40m以上は三塁打。ホームランは4塁分進む。
3. W／↑の長押しで走り、離すと止まる。「走る」ボタンでは到達先まで自動走塁し、「止まる」で止められる。画面左下のミニマップでも現在地と次の塁を確認できる。
4. ホーム→1塁→2塁→3塁→ホームの順に走り、矢印も次の塁へ切り替わる。残っている走者も同じ塁数だけ進む。
5. 走者が実際にホームへ到達した時点で1点を加算し、得点曲を鳴らす。走塁完了後に結果カードが出て、Enterで次の打席へ進む。

空振り・見送り・ファウルでは走塁せず、既存の走者はその塁に残る。走塁中はEnterで次球へ飛ばせない。Escで走者・球・音楽が停止し、Rで得点と走者を初期化する。規定球数終了後は合計得点を表示する。

打者の視点を維持してグラウンド上の走者を操作する。正式なイニング制、攻守交代、守備送球、アウト・盗塁の判定は今回のチャレンジには含めていない。

## 練習モード

従来の5球の打撃・飛距離・タイミング確認を維持する。走塁を挟まず結果から次球へ進む。

Pまたは画面右上の球種ボタンでストレート／カーブ／スライダーを選ぶ。投球中は変更できない。結果画面のボタンは次球の選択を示し、球種バッジは直前の投球を示す。再挑戦でも選択した球種を保持する。

球種は名前に加え、カーブは横に膨らみ、スライダーは逆方向に膨らむ軌道で区別できる。全球種が同じリリース点・打点へ到達する。F3の診断軌道も選択中の球種に対応する。

## 得点曲の入れ替え

Projectで `Assets/_SoftballConnect/Config/DefaultGameConfig.asset` を選び、Inspectorの **Scoring music → Score Music** にAudioClipをドラッグする。WAVやMP3等をUnityへ取り込んで割り当てれば、コードの変更は不要。音量は **Score Music Volume** で調整する。

未指定でも独自合成の短いファンファーレが鳴る。接触音・結果音とは別のAudioSourceを使い、得点イベントで再生する。ポーズで一時停止、再開で続行し、次球・再挑戦・メニュー復帰で停止する。外部から割り当てたAudioClipは破棄せず、生成した音だけを解放する。

## 調整と責務

DefaultGameConfigのSimulationから `RunSpeed`（m/s）、`DoubleDistance`、`TripleDistance`、`CurveBreak`、`SliderBreak`、`BallsPerRound` を調整できる。

- Domainの `BaseRunningPlay` が塁の座標、走者の進行、ホーム到達と進塁数を計算する。
- Applicationの `GameSessionController` がモード、走塁への遷移、得点と結果の確定を管理する。
- Inputアダプタが `Run`（W／↑）と `PitchType`（P）を受け取り、Bootstrapがコマンドへ変換する。
- StadiumView／FeedbackPresenterは走者、矢印、ミニマップ、球種と得点を表示し、ArcadeSoundは `RunsScored` イベントを受けて曲を再生する。

状態はフェア打球の場合 `BallInPlay → BaseRunning → Feedback`。練習・ミス・ファウルは従来どおり `Feedback` へ進む。走塁中のポーズやリセットでも得点が重複しないよう、ホーム到達済み走者を記録する。
