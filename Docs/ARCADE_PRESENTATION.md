# アーケード風の表示（以前の記録）

> 現在の仕様は[打者視点・英語表示・スタジアム](FIRST_PERSON_STADIUM.md)。以下は変更前の履歴で、初期日本語・追従カメラは現在の既定動作ではない。

2026-11-09の依頼に合わせ、以前のアセットへの依存を外し、デフォルメした選手と明るい球場へ表示を変更した。現在のプレイ内容は、5球の投球→打撃→結果→再挑戦。

## 見た目と操作

- 選手は、大きな頭・帽子やヘルメット・目・頬・ユニフォーム・グラブ・小さなスパイクを持つオリジナルの形状。投球時に腕・足・胴体が動き、打者の両手は判定に使うバットのGrip/Tipに追従する。
- 球場は縞模様の芝、内野の土、ベース・打席・ファウルライン、外野フェンス、観客席、看板、照明塔、雲、遠景を生成する。競技距離は引き続きGameConfigのSimulationを使用する。
- メニューにはバットを持ったマスコットと球場を表示する。初回は日本語。言語ボタンで英語へ切り替えられる。
- 打撃中の案内は上部、タイミングバーは右下へ配置する。バーの黄色い範囲が入力タイミングの目安。投球中にSpaceまたは左クリックで一度だけ振れる。
- 打球に軌跡、接触に放射状の光と「ナイスミート！」、結果に飛距離とタイミングを表示する。打球をカメラで追い、結果時には高い位置から球場を見せる。
- 上部の5つのマークは投球ごとの接触結果を示す。黄色がミート、灰色が空振り・見送り。正式な得点ではない。
- 打撃と結果の短い効果音は独自の合成音。Escのポーズに連動し、シーン終了時に音声・描画リソースを破棄する。

Space / 左クリックでスイング、Enterで開始・次球・再挑戦。Rでやり直し、Mでメニュー、Escで停止、Aで投球間のアシスト切替、F3で診断表示。UIボタンをクリックした操作はスイングへ流さない。

## 調整と実装

`Assets/_SoftballConnect/Config/DefaultVisualTheme.asset`で芝・土・チーム・空・フェンスの色、球場名、効果音の音量を変更できる。`EffectsVolume = 0`で効果音を消せる。SurfaceMaterialとTrailMaterialはビルドへ必要なシェーダーを保持するための専用素材。

| ファイル | 役割 |
|---|---|
| ArcadeArt | 形状・色別マテリアル・フィールドメッシュの作成、静的球場の結合、リソース破棄 |
| CharacterView | デフォルメ選手の組み立て、待機・下手投げ・打撃姿勢 |
| StadiumView | 球場、キャラクター、バット・球、軌跡・接触演出、カメラ |
| ArcadeSound | 接触・成功・ミスの短い合成音 |
| FeedbackPresenter | メニュー、投球結果、ポーズ、ラウンド結果、タイミングバー |
| VisualThemeConfig | 表示パレット・マテリアル参照・球場名・効果音量 |
| Localization/ui.json | 日英のUI文言 |

旧CharacterModel・BallModel・BatModelと旧マテリアルの参照は既定テーマから外した。旧アセットやバックアップのファイル自体は残している。新しい表示には外部の画像・モデル・アニメーションを使っていない。`Softball Connect > Create Missing MVP Assets`も新しい専用マテリアルを生成する。

DomainとApplicationの判定・状態遷移は変更していない。守備選手・観客は表示用で、捕球・送球・走塁・対戦のルールは追加していない。
