# 打者視点・英語表示・スタジアム

2026-11-09の追加依頼に対応。現在の標準は**打者の目線、英語で開始、日本語へ切り替え可能**なPC版。

## プレイヤー視点

- `PlayerViewRig/PlayerOrigin/Head`をプレイヤーの視点として使用する。既定の目位置はホーム基準で`(-0.72, 1.65, -0.80)m`。PCの視野角は82度。
- 投球・スイング・接触・打球飛行・結果・次球・再挑戦で、プレイヤー原点を自動移動しない。打球追従カメラや結果の俯瞰カメラへ切り替えない。
- **右マウスボタンを押してドラッグ**すると、PCで首の向きを調整できる。左クリック/Spaceはスイング。
- 打球の方向と距離を画面上に表示する。球が画面外なら左右・上下の方向を案内する。距離はホームからの水平距離の目安。
- 打者の頭や胴体を一人称カメラに映さず、手とバットを表示する。PCの構えはバットを立て、スイング開始後に打撃平面へ下ろす。表示と判定は同じGrip/Tipを使う。
- メニュー背景のカメラは別の観客視点。プレイ中の視点とは分離している。

### 将来のHMD入力

`IHeadPoseSource.SampleHeadPose(dt)`がPlayerOriginに対するローカルの位置・回転を返す。PCでは`DesktopHeadPoseSource`を接続し、将来は`PlayerViewRig.SetHeadPoseSource(...)`でHMDの追跡アダプタへ置き換える。トラッキングによる頭の動きはポーズや結果中も受け取る。

今回、XR SDK・XR Originの実装やHMD接続は追加していない。実機対応には追跡空間のキャリブレーション、XRカメラ/投影、コントローラーのBatInput、VR用World Space UI、実機での表示・操作確認が必要。今回の頭の姿勢テストは仮の入力元を用いた接続テストであり、実機検証ではない。

## 英語・日本語

起動時は英語。言語ボタンまたは**L**で日本語へ切り替える。選択はメニューとゲームの行き来で保ち、アプリの新しい起動では英語へ戻す。文字列は`Localization/ui.json`で管理する。球場名やブランドの英語表記は両言語で共通。

## 球場の変更

芝・土に独自の手続き生成テクスチャを適用し、落ち着いた色に変更した。青い独立座席とコンクリート段床、通路・手すり・ひさし、ダッグアウト、防球ネット、照明塔、スコアボード、街並みの遠景を追加。選手は成人の身長に近い仮モデルを使用する。

外部の画像・モデル・有料アセットを新規導入していない。球場はPrimitiveとメッシュによるプロトタイプで、写真品質の素材・建築モデルではない。守備選手や観客は表示用。打球の競技寸法・結果判定はDomain側の設定から取得する。

## Editorで調整する

Playを停止してから変更し、入り直して反映する。以下のパスは`Assets/_SoftballConnect/`を基準とする。

| 編集先 | 項目 |
|---|---|
| Config/DefaultGameConfig.asset → Player View | 目の位置、PCの視野角、マウス感度 |
| Config/DefaultGameConfig.asset → Simulation | 塁間、投球距離、フェンス距離・高さなどの競技寸法 |
| Config/DefaultVisualTheme.asset | 芝・土・フェンス・空・座席・コンクリートの色、球場名、座席の行数・列数、音量 |
| Config/DefaultVisualTheme.asset → Stadium Visual Prefab | 自分で編集・保存した球場Prefabを使う場合の参照。未設定なら自動生成 |
| Scripts/Presentation/StadiumEnvironment.cs | 自動生成するグラウンド・観客席・防球ネット・施設の配置 |

Prefabを使う場合は、ホームを原点、上を+Y、投手/中堅方向を+Z、1単位を1mとして作る。Configの競技寸法と塁・フェンスの表示を合わせる。表示用Colliderは実行時に無効化し、判定をDomainから独立させない。生成済みHierarchyをPlay中だけ動かした変更は保存されない。

`ArcadeArt`はメッシュ作成・結合に引き続き使用するが、球場の構築は`StadiumEnvironment`、頭の姿勢は`PlayerViewRig`、入力元は`DesktopHeadPoseSource`へ分離した。PC向けの初期実装であり、Questのポリゴン数・生成時間・FPSは未計測。

起動手順は[Editorガイド](EDITOR_GUIDE.md)、実行した確認と未検証事項は[検証記録](VALIDATION.md)を参照。
