### EditModeの対象

- 同条件投球の全サンプル一致と目標点到達。
- 両端判定では見落とす高速交差、同じ空間を異なる時刻に通る場合の非接触。
- アシストの有効幅と、離れた球には当たらないこと。
- フェア/ファウルの境界5条件。
- 地面の補間着地、円形フェンスの交差位置、高さを超えたフェア打球の分類。
- **アシストON/OFFそれぞれ10球連続**のタイミング入力。重複意図を送り続けても1球1接触・1結果で、ラウンド終了・リセットが整合すること。
- 早い/遅いスイング、見送り、結果が自動で次球へ進まないこと。
- Prepare/Windup/InFlight/InPlay/Feedbackでのポーズ停止とリセット。
- 不正状態遷移の拒否と不正設定値の拒否。

### PlayModeの対象

1. Bootstrap→MainMenuのUI開始ボタン→Stadium_PC→5球→各球の結果→ラウンド結果→再挑戦→ポーズ/リセット→メニュー。球ごとのシミュレーションは固定Tickをテストから進めて高速化。日英切替を各結果で実行。予期しないログ例外なし。
2. 仮想KeyboardにSpaceイベントを送り、**Input System→DesktopBatInputSource→Unity Update→Session**を経由してスイングと接触が発生すること、Unity Update中のポーズ/再開で球が停止/再移動すること。

バッチ起動時はGameビューにフォーカスがないため、入力テスト内だけフォーカス制限を解除し、finallyで元のInputSettingsへ戻している。ゲーム本体のフォーカス設定は変更していない。

描画用PNGはURPのSingleCameraRequestで1600×900に出力。実画面の全解像度・全フォント環境や人の操作感を保証するものではない。

### 実行途中で判明した点

- 最初のサンドボックス内Unity起動はUPMソケットのEPERMで失敗。許可された制限外実行で再試行し、コンパイル・テストを完了。
- システム付属の旧NUnitでの試行はNUnit APIの版不一致でコンパイル不可。最終結果はUnity Test RunnerのNUnitを使用。製品コード単独のmcsコンパイルは成功。
- 初回の追加Spaceテストはバッチの入力フォーカスにより失敗。テスト内のフォーカス設定を修正して確認。
- 統一後の描画なし実行では再開テストの30フレーム待機が1/120秒に届かず失敗。経過時間を上限に移動の発生を待つ方式へ修正し、実プロジェクトの最終実行は2/2成功。ゲーム本体の時間処理は変更していない。
- 描画確認に合わせ、環境光を明示し、撮影をURP用のレンダー要求へ修正。日英の文字やボタンの重なりを目視確認。

## Unity起動時のエラー修正（2026-11-09）

実プロジェクトの`Logs/Editor.log`で、次の起動時エラーを確認した。

- `SearchDatabase.EnumerateAll`からの`ArgumentOutOfRangeException`。`UserSettings/Search.index`が存在せず、Play Mode復元時に既定インデックスの作成をスキップしたあと、空のデータベース一覧を参照していた。
- 既存のUnity Cloudプロジェクトへの問い合わせでHTTP 403。Cloudサービスは無効だったが、`PlayerSettings`にプロジェクトIDと組織の紐付けが残っていた。

`SearchIndexSetup`をEditor専用に追加し、Unity 6000.6では遅延初期化より先に不足する既定インデックス設定を生成する。既存の設定は上書きせず、アセットインポート用のワーカープロセスでは実行しない。設定形式は[Unity 6000.6の既定テンプレート](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.6/Modules/QuickSearch/Editor/Indexing/SearchDatabaseImporter.cs)に合わせた。生成物は従来どおりGit管理対象外。

ローカルの無効なCloud紐付けを解除した。Cloud上のプロジェクト自体は変更していない。`ProjectSettings.asset`のAndroidテクスチャ形式に混入していた末尾の`i`も除去した。

起動中の実プロジェクトを閉じず、Assets・Packages・ProjectSettingsと生成キャッシュの一時コピーをUnity **6000.6.8f1 / macOS / Apple Silicon**で検証した。

| 確認 | 結果 |
|---|---|
| 最終コードのUnityコンパイル | 成功 |
| EditMode | **24/24成功**。`TestResults/StartupFix_EditMode.xml` |
| PlayMode | **2/2成功**。`TestResults/StartupFix_PlayMode.xml` |
| 検索設定の復元 | 検索インデックス設定がない状態から既定設定を自動生成 |
| 既存の検索設定の保持 | 再起動前後のSHA-256一致 |
| 対象エラー | 検証ログに検索初期化例外・Cloudプロジェクトの403・C#コンパイルエラーなし |
| 構成検査 | `python3 Tools/validate_project.py`、`git diff --check`成功 |

実プロジェクトの`UserSettings/Search.index`も復元済み。起動中のEditorには設定が読み込まれているため、**Unityの再起動で修正を反映する**。実画面での再起動後の確認は未実施。
